## 🚧 Currently working on

### WealthAI-Copilot
An agentic RAG assistant for wealth advisors, built to be **grounded, cited and compliance-aware**.

| Component | Approach |
|---|---|
| Orchestration | LangGraph (stateful graph with retrieval-grading loops) |
| Retrieval | Hybrid search (dense + BM25) with cross-encoder reranking |
| Data | Public fund KIDs, SNB / ECB / OECD publications, synthetic client portfolios |
| Evaluation | Ragas (faithfulness, answer relevancy, context precision/recall) |
| Safety | Abstains when evidence is missing, no personalised investment advice |
